# Denis Mchunguzi’s Flexbox Lab — v3 Tooltips Edition

An interactive, beginner-friendly CSS playground for experimenting with Flexbox, Grid, spacing, colors, and animations. Includes Swahili tooltips, live preview, generated CSS, presets, save/undo/redo, and HTML/CSS export.

## Run locally
1. Extract the ZIP file.
2. Open the `Denis-Mchunguzi-Flexbox-Lab` folder.
3. Double-click `index.html` to open it in your browser.

## Deploy to Netlify
Upload the extracted folder containing `index.html`, `style.css`, and `script.js` using Netlify’s manual deploy area.
